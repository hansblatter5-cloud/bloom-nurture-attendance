Bloom & Nurture — Attendance Management System


Welcome to the Bloom & Nurture Attendance Management System, a real-time tracking and analytics portal designed for maternal care shops and retail environments.

This repository houses the frontend and management interface for monitoring daily staff check-ins, tracking punctuality thresholds, managing employee directories, and exporting operational compliance reports.

🚀 Key Features
Real-Time Attendance Monitoring: Live tracking of workforce presence, active percentages, and shift status.

Punctuality & Threshold Tracking: Automated monitoring against strict shift cutoffs (e.g., 09:00 AM) to flag late arrivals and on-time arrival rates.

Role-Based Quick Test Switch: Seamless simulation mode allowing instant switching between Store Manager view, Employee profiles (Approved/Pending), and the Entrance Kiosk.

Comprehensive Reporting: Export monthly reports, download CSV files, and generate official printable PDF documentation.

Interactive Activity Logs: Filterable and searchable daily check-in/check-out logs across departments.

🛠️ System Overview & Navigation
The application interface is structured around core operational modules accessible from the main dashboard:

My Daily Check-In: Dedicated portal for staff members to record their arrival and departure status.

Manager Control Panel:

Live Analytics: Instant overview of active staff count, workforce percentages, and late arrival metrics.

Employee Directory: Centralized list of registered personnel across departments.

Monthly Reports: Historical attendance data aggregation and export tools.

Open Entrance Kiosk: Standalone check-in station view for storefront entry points.

💻 Tech Stack & Deployment
Architecture: Static HTML/CSS architecture optimized for fast, responsive cross-device performance.

Hosting: Deployed and hosted continuously via Netlify.

📋 Quick Start
To explore or run the demo locally:

Clone the repository to your local development environment.

Open index.html in your preferred web browser or serve it via a local static server (e.g., Live Server in VS Code).

Use the Quick Test Switch in the top navigation bar to toggle between Manager and Worker permissions.
